# Client logos

Drop official logos here, named exactly as below (`.svg` preferred, `.png`/`.webp` also work), then run `npm run build`.
Only add logos you are authorised to display. Until a file exists, the tile shows the client name as a text wordmark.

- ministry-of-presidential-affairs
- ict
- aldar
- brand-folio
- dalma-mall
- adnoc-tower-3-wtc
- yas-mall
- nation-towers-mall
- kpmg

Tips: transparent background, single-colour or full-colour (they display in grey and turn to colour on hover), roughly 4:1 or wider, at least 240px wide for PNG/WebP.
